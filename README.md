# 💻 Machine Learning Practicals

A collection of Python practical programs completed as part of Machine Learning coursework.

This repository contains experiments and exercises that use NumPy, Pandas, and Matplotlib to perform data processing, statistical analysis, and data visualization tasks.

---

## 🔍 Repository Overview

The practicals included in this repository focus on developing familiarity with the tools commonly used while working with datasets.

Unlike project-based repositories, these programs are individual exercises that demonstrate different operations such as:

* Creating and manipulating arrays
* Working with tabular data
* Reading and processing datasets
* Performing calculations and statistical operations
* Generating charts and visualizations
* Exploring data through analysis techniques

The programs combine multiple libraries wherever required, reflecting how they are typically used together in real applications.

---

## 📌 Core Libraries Used

### NumPy

Used for numerical computing and array-based operations.

### Pandas

Used for handling structured data, data cleaning, and analysis.

### Matplotlib

Used for visualizing data through different types of charts and graphs.

---

## 📈 Areas of Practice

The practicals cover a variety of concepts, including:

* Data handling and preprocessing
* Array operations
* DataFrame manipulation
* Statistical calculations
* Data filtering and transformation
* Dataset exploration
* Graphical representation of data
* Basic analytical workflows

## ▶️ Running the Programs


Navigate to the project directory:

```bash
cd Machine-Learning-practical-s
```

Run any Python file:

```bash
python filename.py
```
